# QSAP License & Backup System

نظام مركزي لإدارة التراخيص والنسخ الاحتياطي لنظام QSAP المدرسي.

## المتطلبات
*   Python 3.8+
*   Flask
*   MySQL (اختياري، يعمل افتراضياً على SQLite)

## التثبيت وتشغيل السيرفر

1.  انتقل لمجلد النظام:
    ```bash
    cd d:\students_empty\License_System
    ```

2.  قم بتثبيت المكتبات المطلوبة:
    ```bash
    pip install -r requirements.txt
    ```

3.  قم بتشغيل السيرفر:
    ```bash
    python app.py
    ```

4.  الدخول للوحة التحكم:
    *   الرابط: `http://127.0.0.1:5000/admin`
    *   اسم المستخدم الافتراضي: `admin`
    *   كلمة المرور الافتراضية: `admin123`

## طريقة العمل

### 1. التفعيل (Activation)
يتم التفعيل عبر الـ Client SDK الموجود في `client_sdk.py`.
*   يقوم البرنامج بإرسال `license_key` واسم المدرسة.
*   يقوم السيرفر بالتحقق وتسجيل الجهاز وإرسال `Token`.

### 2. التحقق الدوري (Check)
*   يقوم البرنامج بإرسال الـ `Token` كل 90 يوم.
*   يرد السيرفر بحالة الترخيص (Active/Expired).

### 3. النسخ الاحتياطي (Backup)
*   يتم رفع ملفات قاعدة البيانات المشفرة إلى مجلد `backups/`.
*   يمكن للـ Admin فقط تحميلها من لوحة التحكم.

## هيكل الملفات
*   `app.py`: ملف التشغيل الرئيسي.
*   `models.py`: جداول قاعدة البيانات (Schools, Licenses, Devices, Logs).
*   `routes/`: الموجهات (API و Admin).
*   `templates/`: واجهات لوحة التحكم (Tailwind CSS).
*   `client_sdk.py`: كلاس جاهز للاستخدام في تطبيق العميل (Django).
